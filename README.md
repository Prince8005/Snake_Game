# Snake Arcade

A neon-styled classic Snake game built with HTML, CSS, and JavaScript.

## Play

**Live game:** [live link](https://snakegame-mu-gilt.vercel.app/)

## Run locally

Open `index.html` in a web browser.

## Controls

- Use the arrow keys or on-screen buttons to move.
- Press **Space** to pause.
- Eat apples to grow and increase your score.
